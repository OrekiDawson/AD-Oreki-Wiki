Web 版入口是  [oreki.net](https://oreki.net/)。源码仓库中的变更不会自动改变正式入口；判断自己正在玩的版本时，以实际打开的站点和页面显示为准，而不是以某个 GitHub commit 或转发链接推断。

## 页面看起来像旧版本怎么办

先强制刷新页面，再确认浏览器没有保留旧的站点资源。不要在问题尚未复现时清除全部站点数据，因为这可能同时删除浏览器里的本地存档。清理缓存或站点数据前，先导出并保存存档副本。

如果刷新后仍然异常，记录页面显示的版本信息、浏览器、操作顺序和实际结果，再到[玩家常见问题](/player/faq/)查找处理方法。页面能打开只说明入口响应，不代表每个游戏状态或存档迁移都正常。

## Web 存档的安全习惯

在更换浏览器、清理站点数据或测试新部署前，先使用游戏内导出功能，把副本保存到浏览器之外。导入后检查阶段、资源、研究和自动购买器，再正常离开并重新打开确认状态仍在；具体迁移步骤见[存档安全](/player/gameplay/saves)。

## 平台互推边界

两端都叫 本 MOD，却可能使用不同的游戏基线、自动化实现和发布版本。Android 的安装包版本、签名与 Activity 生命周期不适用于 Web；Web 的浏览器缓存、站点数据和离线行为也不等于 Android 本地存储。遇到同名功能表现不同，先阅读[原版与 MOD 的区别](/player/gameplay/original-vs-mod)，再分别记录平台与版本。
