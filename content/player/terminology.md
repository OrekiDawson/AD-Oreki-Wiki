有些词第一次出现时像是按钮名称，玩到后面才会发现它们其实描述的是整套成长逻辑。本表先给出玩家需要的含义；更完整的操作和公式，请沿链接阅读对应条目。术语的原始定义可对照  [Antimatter Dimensions Wiki 的 Terminology 条目](https://antimatterdimensions.wiki.gg/wiki/Terminology)，本站译文会在玩家专区页面中注明 本 MOD 的差异。

## 成长与重置

| 术语               | 含义                                                                                                |
| ------------------ | --------------------------------------------------------------------------------------------------- |
| 反物质维度         | 按阶数生产反物质或更高阶维度的生产链。高阶维度通常需要前一阶维度解锁与购买。                        |
| 维度提升           | 早期威望机制。它会重置一部分当前产出，换来新维度或维度倍率。                                        |
| 维度献祭           | 将低阶维度的当前数量换成第 8 维度倍率的机制；已购买的维度和适用升级是否保留，要以当前挑战规则为准。 |
| 反物质星系         | 更高一层的早期重置。它会重置部分维度进度，但提高计数频率效果。                                      |
| 大坍缩（Infinity） | 以当前反物质进度换取无限点数，进入无限阶段。它会重置早期维度进度，但保留相应的永久升级。            |
| 永恒（Eternity）   | 以永恒点数开启的下一层重置，通常会重置无限阶段的临时进度。                                          |
| 现实（Reality）    | 更高层的重置，开启时间研究、膨胀和天神等后期系统；具体保留项取决于游戏阶段。                        |
| 威望（Prestige）   | “牺牲当前进度，换取永久或半永久优势”的统称。维度提升、维度献祭和反物质星系都属于早期威望链。        |

## 资源与系统

| 术语                  | 含义                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------- |
| 无限点数              | 完成大坍缩后获得的资源，用于无限升级等系统。                                                |
| 永恒点数              | 完成永恒后获得的资源，用于永恒升级和相关解锁。                                              |
| 时间研究              | 现实前后的分支研究树。研究点有限时，选择一条分支通常意味着放弃另一条分支的即时效果。        |
| 时间膨胀              | 后期系统。它会改变时间研究和部分资源的成长方式，并为现实准备新的资源。                      |
| 天神（Celestial）     | 现实之后的后期角色与挑战系统，例如 V、Ra、Lai'tela 和 Pelle。每个天神都有自己的规则和进度。 |
| 复制器（Replicanti）  | 会自动增长、并能影响维度或无限进度的特殊资源。复制器的增长速度与上限常受升级影响。          |
| 计数频率（Tickspeed） | 维度生产循环的速度。计数频率越快，维度生产间隔越短；它与维度倍率是不同的加成。              |

## 玩家操作中常见的词

| 术语          | 含义                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------- |
| 自动购买器    | 按设定条件自动购买维度、升级或其他项目的工具。自动化只会执行当前阶段允许的操作。                                 |
| 挑战          | 会改变一条或多条游戏规则的特殊关卡。挑战奖励和完成条件必须以对应页面为准，不能把普通流程中的经验直接套用进去。   |
| 保留项        | 发生重置后仍然存在的资源、升级或解锁。不同重置层和挑战的保留范围不同。                                           |
| 前置条件      | 让按钮、升级或页面出现并可用所需满足的条件。资源足够不一定代表前置条件已经满足。                                 |
| 存档导入/导出 | 将当前存档编码为文本并在另一份游戏实例中恢复。操作前应先保留一份原始备份。                                       |
| 原版          | 本站所译原始 Wiki 对应的《Antimatter Dimensions》规则。原版和 MOD 的数值、界面或自动化差异应分别阅读。 |
| MOD | 本站项目所指的 MOD 版本；它可能调整成长、自动化或界面，不能用原版条目的每个数字替代核对。                        |
