第一次看到反物质停在 `1.80e308`，很像撞上了宇宙的墙。其实那不是游戏结束，而是游戏在问你：愿不愿意把这轮已经堆出的反物质，折叠成另一种更适合投资的资源？

**大坍缩**把反物质换成无限点数（IP），**永恒**再把无限阶段的成果换成永恒点数（EP）。它们不是“失败后重来”，而是两次改变计分单位的换算。理解“这次失去什么、下一轮得到什么”，比记住某个固定秒数更能帮助你判断按钮何时值得按。

## 先分清三种数字

进入无限阶段后，屏幕上常同时出现三种容易混淆的量：

- **反物质**：这一轮生产链正在制造的资源；买维度、计数频率和其他升级会花掉它。
- **无限点数（IP）**：大坍缩的长期收益；用于无限升级、无限维度和打破无限前的准备。
- **永恒点数（EP）**：永恒结算后的更高层资源；它不等于 IP，也不应拿反物质的门槛来套。

可以把它们想成三种不同刻度的尺子。反物质负责把这一轮推到尽头，IP 负责让下一轮更快，EP 则负责打开时间研究和永恒挑战这张更大的地图。

## 第一次大坍缩：把极限兑换成 IP

### 为什么会出现 `1.80e308`

在普通无限中，第一次大坍缩的经典目标是本次无限的最高反物质达到约 `1.7976931348623157e308`。这个数接近双精度浮点数的上限，所以界面常把它显示成 `1.80e308`。数字看起来像科学计算的趣闻，实际也改变了玩法：继续购买低层维度不会让当前反物质无限增长，必须用结算把这一轮的成果带走。

### 什么时候该按

达到门槛后，大坍缩按钮才有资格出现；但“能按”不等于“必须立刻按”。第一次通常应先确认：

1. 是否已经买下当前能负担的无限升级；
2. 本轮继续等待能否带来明显更多的 IP；
3. 是否正在挑战中，挑战规则会不会改变本次结算；
4. 自动购买器是否只是在替你按下真实结算，而不是跳过门槛。

如果下一笔升级能让下一轮快很多，先花 IP 再继续生产；如果生产已经明显变慢，结算通常比守着一串不会再增长的反物质更有价值。

### 大坍缩会保留什么

它会清理本轮反物质和相关的短期生产进度，同时把结算次数与 IP 带入无限阶段。已经购买的长期无限升级不会因为一次普通大坍缩重新变成未购买。具体的维度、计数频率和挑战保留项，应以当前平台按钮的“将失去/将获得”说明为准；挑战、天神和毁灭现实可能覆盖普通规则。

## 打破无限：解除的是上限，不是重置

大坍缩后，如果反物质仍在 `1.80e308` 附近停住，不要把它误解成 IP 不够。**打破无限（Break Infinity）**是一个独立的开关：它允许生产越过原来的反物质上限。

在当前 Web 源码中，`breakInfinity()` 的第一道守卫是大坍缩自动器的间隔已经拉到最小；自动器尚未满级时，调用会直接返回。也就是说，玩家常见的“按钮怎么按都没反应”，可能不是页面故障，而是前置升级没有完成。打破无限后，再考虑继续积累反物质，才有意义；否则只是对着同一面天花板多等一会儿。

打破无限前后的判断可以这样做：

- **上限还在**：检查大坍缩自动器间隔是否已满，以及是否处在会阻止操作的挑战中。
- **上限已破**：比较继续积累反物质带来的 IP 增长和马上结算购买升级的收益。
- **自动化在运行**：确认它读取的是当前阶段的真实状态；自动化不能替你满足打破无限的前置条件。

## 无限阶段不只有一个按钮

打破无限后，无限维度、无限升级和无限挑战会把“生产更多反物质”变成几条互相支撑的路线：

- **无限升级**通常直接改变生产或结算效率，适合先购买能缩短下一轮等待的项目。
- **无限维度**是另一条生产层，不要把它和反物质维度的数量混为一谈；它们的价格和产出属于不同资源系统。
- **无限挑战**会用限制换奖励。挑战里的慢，不一定表示配置错了，可能正是规则要求你换一条生产路径。

当按钮突然变多时，可以按“能立即提高下一轮效率 → 能解锁下一层 → 需要专门准备”的顺序浏览。没有必要为了完成一个当前明显过早的挑战，把整个生产链锁在原地。

## 第一次永恒：IP 换成 EP

永恒是无限之上的第二次重大重置。当前 Web 基线把它判定为：**本次永恒记录中的最高 IP 达到永恒目标**；自动化源码与界面使用的目标约为 `1.797e308` IP。这里比较的是 IP，不是反物质，因此两个阶段可能都出现 `e308`，却是两把完全不同的尺子。

第一次永恒前，先确认自己已经理解这次交换：它会清理大量无限阶段的短期进度，却给予 EP、永恒次数以及后续系统入口。若你只是刚好达到门槛，IP 升级或无限维度还能显著提升下一轮，那么多跑一轮可能更舒服；若生产已经进入长时间停滞，永恒通常是把时间重新换成成长的正确方式。

永恒后的低数字不是存档倒退，而是计分单位换了。就像把一大袋硬币换成一张更高面额的钞票，桌面上的硬币变少了，购买力却进入了另一层。

## 永恒之后：研究树决定路线

永恒点数和时间之理（TT）会把游戏从“哪一个按钮更快”带向“哪一种路线更适合当前目标”。时间研究有前置关系和分支，买研究前先看：

1. 它是否通向当前想解锁的系统；
2. 前置研究是否完整；
3. 这次选择会不会排斥另一条分支；
4. 下一次永恒是否能更快赚回投入。

永恒挑战（EC）则把研究路线和特殊限制绑在一起。某个入口打不开时，先看研究和资源条件，而不是在页面上反复点击；挑战中的结算也应遵守真实门槛。完成挑战后得到的奖励，通常会让下一轮研究或永恒更快。

## 原版与 Oreki Edition 的区别

原版与 MOD 共享维度、无限、永恒和挑战的成长骨架，但不能把一端的自动化行为当成另一端的承诺：

- 原版的无限/永恒门槛和重置保留项以原版机制为准；
- Oreki Edition 可能用阶段调度器接管购买、等待和真实结算；
- Android 与 Web 的按钮布局、调度节拍和部分保留规则可能不同；
- 自动化可以替你执行已经满足条件的动作，不能凭空生成 IP、EP 或跳过研究前置。

若某个后期页面提前出现，先核对实际资源、解锁状态和当前挑战，不要把“看见入口”当成“已经完成阶段”。差异集中见[原版行为与 Oreki Edition 修改](/player/gameplay/original-vs-mod)，自动化见[智能自动购买器](/player/gameplay/automation)。

## 一条实用的重置判断法

每次准备点击重置时，问自己三句：

1. 这次会清掉哪一层进度？
2. 获得的资源能立即购买什么？
3. 如果再等五分钟，收益是更多资源，还是只是更大的数字？

第三个问题尤其重要。增长曲线最会骗人的地方，是“数字还在涨”看起来像“等待仍然值得”。当下一层资源能够缩短后续所有循环时，重置不是中断游戏，而是把时间从低利率账户转到高利率账户。
