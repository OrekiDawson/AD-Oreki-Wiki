《反物质维度》的开局有一种很特别的错觉：数字已经开始疯长，真正重要的按钮却像在等你犯错。其实不用急着背攻略。前几分钟只需要学会一条循环：花反物质买生产力，生产力变慢后进行一次重置，用重置带来的永久优势把下一轮推得更远。

这篇指南面向全新存档，目标是走到第一次**大坍缩**。已有存档请直接从当前阶段继续，不要为了“按教程重来”清空进度。

## 先选一个安全的入口

### Web

打开 [oreki.net](https://oreki.net/)。Web 存档保存在当前浏览器的站点存储里；换浏览器、开隐私窗口或清理站点数据前，先用游戏内的存档工具导出备份。网页能打开不等于存档已经同步到别的设备。

### Android

从[下载与版本说明](/player/download-and-version/)进入 Android Releases。第一次游玩优先选稳定版；标为 `Pre-release` 的 APK 是测试候选，适合愿意备份存档并接受未知问题的玩家。安装或覆盖更新前先导出存档，尤其要留意签名或包名变化可能导致无法覆盖安装。

Android 和 Web 的核心成长链相近，但不要把一端的按钮位置、保留规则或版本行为硬套到另一端。遇到差异时，以当前版本的按钮说明和[原版与 Oreki Edition 的区别](/player/gameplay/original-vs-mod)为准。

## 开局只看懂五件事

| 看到的东西  | 它在做什么                                             |
| ----------- | ------------------------------------------------------ |
| 反物质      | 当前可以花掉的基础资源；留在账户里不会自动变成更高效率 |
| 第 1–8 维度 | 一条生产链；高层维度生产低层维度，低层最终转成反物质   |
| 计数频率    | 让生产链更快的倍率来源；能买时通常值得优先考虑         |
| 维度提升    | 用一次短期重置换取更强的生产和更高维度解锁             |
| 反物质星系  | 更高一层的重置，把前面的循环压缩成更强的长期加成       |

数字越大不代表这一次购买越划算。开局的乐趣就在于：你不断把眼前的反物质换成更快的机器，再看机器把数字推过刚才的门槛。

## 从零走到第一次大坍缩

### 1. 先让生产链转起来

购买能买得起的低层维度，再补充生产上一层维度的高层维度。新档不必囤着反物质；如果某个按钮能提高产量，花掉资源通常比等待更快。

买不起时，先等待生产；买得起后，优先购买能明显提高整条链效率的项目。出现“购买最大数量”时，它只是一次替你计算多次购买，不是新的重置。

### 2. 到门槛就做维度提升

维度提升按钮会写出条件和会失去的东西。按下后，当前维度和部分短期进度会归零，但维度提升次数、加成以及后续解锁会留下来。第一次通常围绕最高已解锁维度的数量展开；不要只盯着反物质余额。

普通阶段的 Web MOD 可能保留部分反物质，Android 的具体行为则随发布版本而定。无论是哪一端，维度、计数频率和维度提升之间的重置关系都应以按钮提示为准。

### 3. 用星系换一条更陡的曲线

反物质星系需要若干次维度提升。它会让你再次回到较早的生产阶段，看起来像倒退，实际是在购买更强的长期倍率。满足条件后，星系通常比继续攒一小笔反物质更值得；按钮旁的“将失去”和“将获得”就是最可靠的说明书。

### 4. 把最高反物质推到门槛

第一次大坍缩的经典门槛接近浮点数上限 `1.7976931348623157e308`，界面常显示为 `1.80e308`。这里的关键是**最高反物质**，不是当前余额：如果你已经达到过门槛，后来花掉资源，进度仍可能已经满足条件。

达到门槛后，确认大坍缩按钮。开启自动购买器时，Oreki Edition 可能替你按下真实的结算入口，但不会凭空制造达到门槛所需的生产。

## 大坍缩之后先做什么

大坍缩会把你带进无限阶段，并给予无限点数（IP）。第一次不要急着追所有新系统：

1. 用 IP 购买当前可用的无限升级。
2. 再跑几轮，比较每次大坍缩获得的 IP 是否增加。
3. 阅读[无限与永恒](/player/gameplay/progression-infinity-eternity)，再决定何时挑战下一层重置。

“按钮出现了”与“现在按下最划算”不是一回事。无限之后的重置会逐渐变成一串互相咬合的门槛，先弄清楚保留什么，再追求速度，会少走很多弯路。

## 卡住时不要先清档

按下面顺序排查：

1. 看自己是在新档、无限、挑战还是其他阶段；不同阶段的按钮规则可能不同。
2. 看按钮上的具体条件，而不是只看资源总数；常见缺口是维度数量、IP 或前置研究。
3. 检查自动购买器总开关和间隔设置；关闭自动化不会阻止手动购买。
4. 如果刚切换版本或设备，先导出当前存档，再处理安装和导入问题。
5. 仍不清楚时，记录平台、版本、阶段、按钮文字和复现步骤，查阅[玩家常见问题](/player/faq/)。

不要把完整存档、账号信息或未脱敏日志直接公开。
