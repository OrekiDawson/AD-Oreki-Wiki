第一次打开 Oreki Edition 时，先确认平台与版本，再从一个全新存档开始。Android 与 Web 共用相似的核心玩法，但安装方式、存档载体和版本记录不同；不要把一端的历史通关结果直接当成另一端当前版本的验收结果。

## 选择游玩平台

| 平台 | 适合情况 | 开始方式 |
| --- | --- | --- |
| Android | 希望使用独立 APK、离线游玩并保留本地存档 | 从 [下载与版本说明](/player/download-and-version/) 进入正式发布入口 |
| Web | 希望直接在浏览器游玩，便于跨设备访问最新部署 | 打开 [Oreki Edition Web](https://oreki.net/)，或从 GitHub 源码仓库本地运行 |

两端都应以真实新档为起点判断阶段节奏。存档导入前先保留原文件备份，尤其不要用旧构建的存档或运行截图代替当前候选版本验收。

## 第一次打开后做什么

1. 从第一反物质维度开始，先购买能直接提高反物质产量的升级。
2. 解锁维度提升与反物质星系后，观察重置带来的长期收益，而不是只追求当前数字。
3. 进入无限、永恒和现实后，逐层阅读 [玩法机制](/player/gameplay/)，避免把更高阶段系统的规则套到早期。
4. 开启自动化前先确认它当前管理的购买器与目标；自动购买器不是跳过玩法内容的许可。

## 怎样判断自己看的是哪一版

Android 正式版优先记录 GitHub Release 标签、版本名和 APK 哈希；Web 以部署 Commit 与线上页面为准。玩家无需理解构建流程，但遇到存档或进度问题时，提供准确平台、版本和发生步骤，能显著减少误判。版本入口见 [下载与版本说明](/player/download-and-version/)。
