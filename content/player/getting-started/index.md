这篇教程只解决一件事：**从全新存档开始，理解前几分钟该看什么，并完成第一次大坍缩。**

你不需要先记住后面的永恒、现实或天神内容。先学会一个循环：买维度提高产量，偶尔重置换取更强加成，反物质增长变慢时再继续买。失败一次不会毁掉存档，真正需要谨慎的是清档、导入和更换版本。

## 第一次进入游戏

### 网页版

打开 [Oreki Edition Web](https://oreki.net/)，等待游戏载入。首次进入时如果出现说明或确认按钮，按页面提示继续即可。浏览器地址应保持为 `oreki.net`，不要在陌生镜像站输入自己的存档。

建议先允许网页保存本站数据。游戏依靠浏览器本地存储保存进度；清除站点数据、使用隐私窗口或更换浏览器，都可能让原来打开的存档消失。

### Android

从 [Android 发布页](/player/download-and-version/)确认版本并安装 APK。第一次启动通常会出现“开始游戏”按钮；以后再次打开，应从已有存档槽继续，而不是在确认框中清空进度。

`Stable` 是面向正常游玩的版本，`Pre-release` 用于测试，可能包含尚未解决的问题。只想开始玩时，优先选择 Stable，不要因为测试版版本号更高就直接覆盖原来的稳定版。

## 主界面先认识五个词

新档首页最重要的区域可以直接从屏幕上找到：

| 界面名称 | 作用 | 第一次怎么用 |
| --- | --- | --- |
| **反物质** | 当前拥有的资源 | 它会持续增长；购买会消耗它 |
| **第一维度**到**第八维度** | 八层生产链 | 低层生产资源，高层生产下一层；新档不会马上全部出现 |
| **计数频率** | 提高反物质维度的生产速度，等效为产量倍率 | 买得起时购买，效果通常会直接显示为倍率 |
| **维度提升** | 用一次重置换取维度数量、上限和新维度 | 当前购买明显变慢、按钮条件满足时使用 |
| **反物质星系** | 增强计数频率并提供新的成长段 | 在维度提升之后逐步解锁，价格与前置条件会写在按钮旁 |

Android 和 Web 的布局不同，但资源名称和成长顺序一致。先看按钮上的价格、当前数量和加成，不需要记住所有数字。

## 前几分钟实际怎么玩

### 1. 先买能立刻提高产量的维度

开局时第 1–4 维度已经解锁：先购买第一维度打出产量，再补充第二、第三维度（它们分别生产上一层的维度），并让第四维度逐步累积到 20 个——第一次维度提升要求当前最高已解锁维度达到 20 个；第 5–8 维度要靠维度提升解锁。按钮显示 `价格` 时表示买一个；显示 `购买最大数量` 或类似选项时，会一次消耗更多资源。

不确定时可以直接用较省心的顺序：

1. 出现新的维度提升解锁项时，先解锁第 5–8 维度。
2. 八个维度都可购买后，交替购买价格最低、对整条生产链提升最明显的项目。
3. 计数频率买得起就提高；它会让同一批维度生产得更快。
4. 不要只囤着反物质。这个游戏的主要成长方式就是花掉资源再赚回来。

当前 MOD 可能提供“最大”按钮或自动购买。自动购买打开时仍要观察生产是否在增长；如果数字长时间完全不变，再到 [智能自动购买器](/player/gameplay/automation) 和 [玩家常见问题](/player/faq/)检查设置，不要先清档。

### 2. 变慢时做维度提升

维度提升按钮会显示下一次提升的条件和加成。满足条件后按下，会重置当前维度并强化后续生产；随着次数增加，还会开放更高层维度。

**原版**中，维度提升通常会清空当前反物质。**当前 Web 的 Oreki Edition** 在不在挑战、天神或毁灭现实的普通阶段会保留当前反物质，但维度、计数频率与其他重置项仍按游戏规则处理。Android 的具体构建不能只凭“都属于 Oreki Edition”就假定与 Web 完全相同；请以当前 APK 的按钮说明和实际表现为准，版本差异见[原版与 Oreki Edition 的区别](/player/gameplay/original-vs-mod)。

### 3. 用星系推进下一条成长链

反物质星系通常要求先完成若干次维度提升。按下后会重置维度、计数频率与维度提升，并增强计数频率升级的效果。它看起来像“退回起点”，实际是把下一次循环抬到更高效率。

当维度提升收益已经很小、而星系按钮满足条件时，先做星系通常是合理的。当前 Web MOD 的普通阶段可能保留当前反物质；Android 是否保留仍取决于实际构建，其他重置项始终要按按钮说明判断。

## 什么时候能进行第一次大坍缩

游戏要求本次无限中的**最高反物质**达到约 `1.7976931348623157e308`，界面上常显示为 `1.80e308`。这不是靠修改资源或提前点按钮完成的阶段解锁；必须由真实生产达到门槛。

当前界面可能通过“无限进度”一类的进度条显示距离门槛还有多远。进度条没有满时，继续购买维度、提高计数频率并完成维度提升或星系；只盯着反物质当前值而不购买，反而会更慢。

门槛达到后：

- **原版**会出现“大坍缩”按钮，由玩家确认后结算。
- **Oreki Edition** 在自动购买器总开关开启时可能自动完成这一步；这是自动化代替你按下真实结算入口，不是跳过条件。
- 如果你关闭了自动化，或按钮一直没有出现，先核对最高反物质、自动购买器总开关和当前是否在挑战中，再查看[玩家常见问题](/player/faq/)。

## 第一次大坍缩之后

结算完成后，游戏进入**无限**阶段，并给予无限点数（IP）。你会看到新的“无限升级”等内容，但并非所有后续系统都会一次解锁。

接下来可以先做三件事：

1. 用 IP 购买当前买得起的无限升级，尤其注意能提高 IP 收获或生产倍率的项目。
2. 再做几轮生产与大坍缩，观察每次获得的 IP 是否增加。
3. 阅读[无限与永恒](/player/gameplay/progression-infinity-eternity)，理解“打破无限”需要的前置条件。

**第一次大坍缩不等于可以立刻打破无限。** 原版需要先满足大坍缩自动购买器的间隔等条件；当前 MOD 的自动化还会等至少两次无限后再尝试。按钮暂时不可用是正常门禁，不是点击次数不够。

## 重置会失去什么

不同按钮处理的范围不同。第一次游玩不必背完整表，只要先记住：

| 操作 | 主要失去 | 主要保留或获得 |
| --- | --- | --- |
| 维度提升 | 当前维度、计数频率及部分本轮进度；原版还会失去当前反物质 | 维度提升次数、加成，并可能解锁更高维度 |
| 反物质星系 | 维度、计数频率、维度提升与部分本轮进度；原版还会失去当前反物质 | 星系数量、更强的计数频率效果 |
| 大坍缩 | 本轮反物质及相关生产进度 | 无限次数、IP 和已经取得的长期升级 |

上表只用于第一次游玩的方向判断。当前 Web MOD 在普通阶段可能保留反物质，但“保留反物质”从不表示维度不会被重置；Android 是否保留同样以实际版本为准。挑战、天神和毁灭现实会覆盖普通规则，进入这些系统后应阅读对应攻略。

## 更新或导入前先保护存档

准备更新 APK、切换 Stable 与测试版、导入旧档或尝试另一平台时，先在游戏内导出或备份存档。网页版还应避免清除浏览器站点数据；Android 若使用系统清理工具，要确认它不会连同应用数据一起删除。

**不要为了跟着教程而清空已有进度。** 教程描述的是新档路径；已有存档直接从当前阶段继续即可。Android 与 Web 的存档不能在没有实际验证的情况下假定可以直接互换，跨平台导入前请先看[存档兼容与自动保存](/player/gameplay/saves)。

## 卡住时按这个顺序检查

1. **看当前阶段**：确认自己是在新档、无限、挑战还是其他系统，不要用上一阶段的按钮判断下一阶段。
2. **看真实资源与价格**：按钮灰掉经常只是反物质、IP、维度数量或研究前置不够。
3. **看自动购买器总开关**：关闭后不会替你购买或结算，但手动操作仍应可用。
4. **看当前挑战**：挑战会临时改变价格、产出和重置规则。
5. **先导出存档再排查安装或版本问题**：不要通过反复清档、改存档 JSON 或强开后期页面掩盖问题。

仍然无法判断时，可把版本、平台、当前阶段、按钮文字和复现步骤发到[玩家常见问题](/player/faq/)对应条目；不要公开包含账号、个人信息或未脱敏的完整存档。
