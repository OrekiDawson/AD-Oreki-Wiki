这篇只解决新档的第一件事：看懂屏幕上的资源，并让生产链自己跑起来。你不需要先知道永恒、现实或天神；先把“买资源 → 提高产量 → 用重置换效率”的循环走顺。

## 第一次进入

### Web

打开 [Oreki Edition Web](https://oreki.net/)，等待游戏载入。首次出现说明或确认按钮时按页面提示继续。地址应保持为 `oreki.net`，不要在陌生镜像站输入存档。浏览器本地存储保存进度，隐私窗口、换浏览器或清除站点数据都可能让原存档消失。

### Android

从[Android 发布页](/player/download-and-version/)确认版本并安装 APK。第一次启动通常会出现开始游戏按钮；再次打开时应从已有存档槽继续，不要在确认框中清空进度。只想正常游玩时优先选择 Stable，不要因为测试版版本号更高就覆盖稳定版。

## 主界面的五个词

- **反物质**：当前资源，购买会消耗它。
- **第一到第八维度**：层层生产的链条，低层生产资源，高层生产下一层。
- **计数频率**：提高维度生产速度的倍率来源。
- **维度提升**：用一次重置换取更强生产和更高维度解锁。
- **反物质星系**：进一步增强计数频率并开启新的成长段。

Android 和 Web 的布局不同，但先看按钮上的价格、数量和加成即可，不必背住所有数字。

## 前几分钟怎么花资源

1. 先买能立即提高产量的低层维度，再逐步补齐高层维度。
2. 出现新的维度提升解锁项时，优先解锁第五至第八维度。
3. 计数频率买得起就提高，它会让同一批维度生产得更快。
4. 当维度提升条件满足且购买明显变慢时，执行一次维度提升。
5. 维度提升收益变小、星系条件满足时，考虑执行反物质星系。

不要只囤着反物质。这个游戏的主要成长方式就是花掉资源，再用更高的生产速度赚回来。当前 MOD 可能提供“最大”按钮或自动购买；如果数字长时间完全不变，再看[智能自动购买器](/player/gameplay/automation)和[玩家常见问题](/player/faq/)。

## 卡在开局时

- 价格买不起：先等待低层维度生产，再购买能提高整条链的项目。
- 维度提升按钮灰色：看按钮列出的维度数量和其他前置，不要只看反物质。
- 星系后数字变小：这是重置的一部分，先确认星系数量和生产倍率是否增加。
- 浏览器或 Android 重新开始：先停止操作，检查是否误用了隐私窗口、清除数据或清空存档槽；不要继续覆盖唯一备份。

准备好第一次大坍缩后，继续读[第一次大坍缩与进入无限](/player/getting-started/first-crunch)。
