第一次打开《反物质维度》时，屏幕上只有一个有点荒唐的目标：让一个看似普通的数字不断变大。很快你会发现，真正的主角不是反物质，而是**重置**。每一次把已经积累的东西归零，都会换来更快的生产、更高的上限，或一套全新的规则。

《反物质维度》（Antimatter Dimensions）是一款放置增量游戏。玩家购买维度、升级生产链，在合适的时机进行维度提升、星系、大坍缩、永恒和现实等重置，逐层打开新的成长系统。本文先建立原版的整体地图，再说明 Oreki Edition 应该到哪里查差异；具体数值和版本行为以对应条目为准。

## 维度为什么像一条流水线

反物质维度不是八个并列的“钱袋子”。第一维度直接生产反物质；第二维度生产第一维度；第三维度生产第二维度，依此向上。高阶维度绕一圈，最终仍会变成更快的反物质增长。

原版共有八级反物质维度。新档开始时只开放低阶维度，其余维度要靠维度提升逐步解锁。购买时，眼前最便宜的升级不一定是最好的升级：一次高阶维度购买可能要等一会儿，但它会抬高整条生产链；一次低阶倍增则能立刻让当前数字跳一截。早期的乐趣，就藏在这两种收益的时间差里。

维度数量和生产速度不断上升后，游戏会用更高的价格和新的重置机制把增长重新压回“需要做选择”的范围。指数增长看起来无敌，价格也会以指数增长；当等待开始变得不划算，重置往往才是正确答案。

## 重置不是惩罚，而是换一条更快的起跑线

本作的重置层级由浅入深：维度提升和星系解决早期生产瓶颈；达到约 `1.80e308` 反物质后进行大坍缩，获得无限点数并进入无限阶段；继续推进后，永恒带来永恒点数和时间研究；再往后，现实把永恒及以下的积累换成现实机器、符文和复兴等更高层奖励。

每层重置都遵循同一个反直觉规律：**眼前损失越明显，长期收益越重要**。大坍缩后反物质归零，但无限点数能让下一轮快得多；现实会清空大量熟悉的系统，却把符文、现实升级和自动化带回新的起跑线。不要把“当前数字变小”直接等同于失败，要看重置是否换来了新的永久能力。

成长顺序可以先用这张地图记住：

| 阶段       | 主要资源或系统               | 玩家正在学什么                 |
| ---------- | ---------------------------- | ------------------------------ |
| 反物质阶段 | 维度、维度提升、星系         | 怎样让生产链转得更快           |
| 无限阶段   | 无限点数、无限升级、无限挑战 | 什么时候值得大坍缩             |
| 永恒阶段   | 永恒点数、时间之理、时间研究 | 如何用研究树选择成长方向       |
| 现实阶段   | 现实机器、符文、复兴、自动化 | 怎样把整套流程压缩成更快的循环 |

阶段之间不是四个互不相干的游戏。后层奖励会反过来加速前层，前层也会决定后层能否顺利启动。可以从[无限与永恒](/player/gameplay/progression-infinity-eternity)和[现实与时间研究](/player/gameplay/reality-time-studies)继续阅读。

## 挑战把“会增长”变成“会思考”

挑战会暂时改变熟悉的规则，例如限制某类升级、改变生产方式或要求在特定条件下完成目标。它们的价值不只在奖励：挑战迫使玩家理解平时被倍率掩盖的因果关系——到底是维度数量在起作用，还是速度、复制粒子和重置时机在起作用？

完成挑战后，奖励通常会永久改善某一层成长，或打开更深的研究路线。进入前应看清条件，结算时则以游戏实际判定为准；按钮出现、计时结束和挑战真正完成并不总是同一件事。详见[挑战与真实结算](/player/gameplay/challenges)。

## 自动化把点击变成策略

随着进度推进，自动购买器、自动重置和更高层的 Automator 会接管重复劳动。自动化并没有消灭玩法，而是把问题从“现在点哪个按钮”换成“什么时候允许它重置、资源门槛设在哪里、这一阶段是否应该先保留研究或符文”。

因此，自动化出错时不要只调一个数字。先确认当前阶段、重置层级、挑战限制和策略切换是否一致；一次现实或永恒会改变之前有效的购买顺序。[智能自动购买器](/player/gameplay/automation)适合查具体操作，[玩家常见问题](/player/faq/)适合处理按钮、安装和进度异常。

## 原版与 Oreki Edition 的关系

Oreki Edition 是基于《反物质维度》的 MOD，不是原版的官方版本。它在 Android 与 Web 两端维护自己的界面、自动化和体验改动；同名机制的具体数值、默认策略和发布状态，不能只凭原版记忆推断。需要比较两者时，先看[原版行为与 Oreki Edition 修改](/player/gameplay/original-vs-mod)，再按页面标注的平台和版本阅读。

存档也应分开看待。原版、MOD、Android 和 Web 之间可能存在兼容目标，但不意味着任意版本都能安全互导；在更新或换平台前，请先阅读[存档兼容与自动保存](/player/gameplay/saves)。

## 这款游戏的“科学幻想”在哪里

“反物质维度”这个名字听起来像是在讲粒子物理，实际玩法却把科学词汇变成了可玩的数学隐喻：维度是生产链，指数是速度，重置是把短期积累兑换成长线结构，现实则像把整套实验装置拆掉，只留下更好的仪器图纸。

它并不要求玩家先学会高等数学，但会不断奖励一种很数学的直觉：看见 `10^x` 时，真正重要的可能不是 `x` 的当前数值，而是下一次重置能让 `x` 以什么速度增长。数字越大，选择越像工程；而每次回到零点，恰好提醒你这仍然是一款游戏。
