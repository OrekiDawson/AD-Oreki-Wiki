本页是社区 Wiki 的**术语**条目，收录**佩勒（Pelle）的「用词变化（Wordshifts）」**：佩勒作为多维存在，其语言中的词语会随语境在多个维度间变化，因此写作 `[词A/词B/词C]` 的形式表示同一概念的不同层面对应词。

> 本页译自社区 Wiki 同名条目。表格保留原文的三列结构与内部代号（Codename）；含义列是对原文说明的中文翻译。

## 佩勒的用词变化

| 用词 | 含义 | 内部代号 |
| --- | --- | --- |
| [Destroyed/Annihilated/Nullified] | 用于广告加成，表示该效果已被禁用。此词仅在移动端使用。 | *无* |
| [Infinite/Forever/Eternal] | 用于描述与无限、永恒打交道的存在（佩勒）的「永久性」，暗示其强于「无限」。 | forever |
| [Song/Dance/Charade] | 指玩家与天神之间无休止的战争；该词用于嘲弄玩家的挣扎。 | dance |
| [False/Deity/Destroyer] | 玩家（也是整个游戏的主角）的称号：虚假的、恶魔般的终结召唤者。 | destroyer |
| [Destiny/Mandate/Goals] | 佩勒语言中的「毁灭」。玩家所做之事需要一个更强的名字；「含蓄」是关键——承认它已足够具有毁灭性。 | mandate |
| [Eternal/Deity/Monarch] | 佩勒（反物质之神、众神之首）给自己加上的称号。「Eternal」指佩勒能跨越时间线保留记忆。 | eternal |
| [Lesser/Deity/Monarch] / [Lesser/Deities/Monarchs] | 其余 6 位[天神](/player/original/ow-celestials)：他们是更高层级中的强大存在，但暗示臣属于佩勒。 | lesser/deities |
| [Missing/Unseen/Erased] | 对与佩勒直接或间接相关的存在/事物的「彻底毁灭」；被承认本身就已足够有力量。 | unseen |
| [Conflict/Battle/End] / [Conflicts/Battles/Ends] | 指玩家与天神之间无休止的宇宙冲突。该词也承认：若玩家成为这场冲突的胜者，宇宙将会终结。 | battle/battles |
| [Amusing/Confusing/Laughter] | 含义未知且缺乏准确定义；目前用于描述某位天神拙劣地处理情感概念，并作为「荒谬（Ludicrous）」的替代。 | confusing |
| [Misconstrue/Deceive/Trick] | 多维存在的问题在于：一个维度中的谎言在另一个维度中是真相。该词指讨论维度结构时的误导性陈述，而不只是维度内部的欺骗。 | misconstrue |
| [Alter/Reverse/Manipulate] | 「改变」时间的用词，或指玩家为回到如此久远之处所做的、连他们自己也尚未弄明白的事。此语境下时间是一个维度。 | reverse |
| [Single/Filament/Stars] | 一个单一的星系。隐含意味是佩勒尚未意识到「人造星系」是什么，仍以为它天然存在，因此用复合词描述；与星系生成器相关。 | single |
| [Cluster/Filament/Stars] | 指[星系超星系团](https://antimatterdimensions.wiki.gg/wiki/wikipedia%3ASupercluster)。 | cluster |
| [Mutually/Assured/Destruction] | 「相互保证毁灭（Mutually Assured Destruction）」。 | assured |
| [Eternal/Deity/Destroyer] | 若佩勒对玩家使用[相互保证毁灭]理论上的称号，表明祂会变得像玩家一样的毁灭者。 | *无* |
| [Inevitable/Irreversible/Undying] | 指佩勒裂隙。这是较旧的称号，因为佩勒后来意识到它略有偏差。 | *无* |
| [Scycophant/Deity/Monarch] | 给[特蕾莎](/player/original/ow-teresa)的称号：她以自己的角色为荣，且总是第一个倒下。 | sycophant |
| [Tired/Deity/Monarch] | 给[鹿颈长](/player/original/ow-effarig)的称号。 | tired |
| [Usurper/Deity/Monarch] | 给[无名氏](/player/original/ow-nameless-ones)的称号：他们总是替太阳神的篡位背锅。 | usurper |
| [Pride/Deity/Monarch] | 给[薇](/player/original/ow-v)的称号：她以自己的成就为傲，尽管这些成就在「时间」之后失去了意义。 | pride |
| [Forgotten/Deity/Monarch] | 给被遗忘的[太阳神](/player/original/ow-ra)——真正的篡位者的称号。 | forgotten |
| [Compassion/Shame/Idiocy] | 「怜悯」的用词；用于无名氏替篡位者背锅的语境。 | shame |
| [Paramount/Deity/Monarch] | 给[莱特拉](/player/original/ow-laitela)的称号：祂是二把手，对众天神拥有权力，但只臣属于佩勒；佩勒认为祂「有些不可知」，这也是佩勒并不完美的证明。 | paramount |
| [Generator/Filament/Stars] | 指星系生成器。 | filament |
| [Elementary/Inevitable/Irreversible] | 指佩勒裂隙；与 [Inevitable/Irreversible/Undying] 相比用词略有变化。 | inevitable |
| [Unbroken/Eternal/Connection] | 用于把佩勒裂隙与星系生成器连接起来；这是佩勒不可阻挡的力量之一。 | unbroken |
