下表列出[被毁灭的现实](/player/original/ow-pelle)中会改变星系强度的来源。它与[星系数量明细](/player/original/ow-tickspeed-galaxy-breakdown-doomed)不同：前者回答“有多少个有效星系”，本页回答“每个星系的效果应乘多少”。

| 加成来源 | 说明 | 倍率 |
| --- | --- | ---: |
| [无限升级](/player/original/ow-infinity-upgrades) | 所有星系的效果翻倍 | $\times 2$ |
| [打破无限](/player/original/ow-break-infinity)升级 | 所有星系的效果提高 50% | $\times 1.5$ |
| [无限挑战](/player/original/ow-infinity-challenges) 5 | 所有星系的效果提高 10% | $\times 1.1$ |
| [成就](/player/original/ow-achievements) 86 | 所有星系的效果提高 1% | $\times 1.01$ |
| [成就](/player/original/ow-achievements) 178 | 所有星系的效果提高 1% | $\times 1.01$ |
| [时间研究](/player/original/ow-time-studies) 212 | 根据时间碎片提高所有星系的效果 | $\times \min\left(\log_2(\text{Time Shards})^{0.005},~1.1\right)$ |
| [时间研究](/player/original/ow-time-studies) 232 | 根据反物质星系数量提高所有星系的效果 | $\times \left(1+\frac{\text{Antimatter Galaxies}}{1{,}000}\right)^{0.2}$ |
| [佩勒升级](/player/original/ow-pelle-upgrades)“星系力量” | 每次升级使星系力量提高 2% | $\times(1+0.02U)$；$U$ 为购买次数 |
| 佩勒裂痕的第 2 个里程碑 | 当复制器超过 $1\text{e}1{,}300$ 时，所有星系的效果提高 10% | $\times 1.1$ |
| 被毁灭的现实效果 | 所有星系的效果仅有原来的 50% | $\times 0.5$ |

原文还列出被佩勒[毁灭/湮灭/无效化]的[诅咒符文]、[现实符文](https://antimatterdimensions.wiki.gg/wiki/Glyphs)和[虚幻升级](/player/original/ow-imaginary-upgrades)。这些条目在原文表中只是说明其效果已被移除，并没有额外倍率；符文总览尚未建立本站独立译文，暂保留英文入口。
