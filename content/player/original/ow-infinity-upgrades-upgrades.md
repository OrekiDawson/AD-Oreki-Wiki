本页是[无限升级](/player/original/ow-infinity-upgrades)主条目嵌入的**不可重复升级表**，也是社区 Wiki 的子页面。升级按四列排列，每列四项；除每列第一行外，每项升级的前置都是**同一列**的上一项升级；第一行的所有升级一开始就可购买。

> 升级名称是游戏内标签，保留英文原名；效果与公式已翻译。

| ID | 成本（IP） | 描述 | 效果 / 其他细节 |
| --- | --- | --- | --- |
| **第 1 列** |  |  |  |
| timeMult | $1$ | 反物质维度获得基于游玩时间的倍率 | $\left(\frac{Minutes}{2}\right)^{0.15}$ |
| 18Mult | $1$ | 第 1 与第 8 反物质维度获得基于无限次数的倍率 | $1+\frac{Infinities}{5}$ |
| 36Mult | $1$ | 第 3 与第 6 反物质维度获得基于无限次数的倍率 | $1+\frac{Infinities}{5}$ |
| resetBoost | $1$ | 维度提升与反物质星系所需的维度数量减少 $9$ | $-9$ |
| **第 2 列** |  |  |  |
| dimMult | $1$ | 提高「购买 10 个反物质维度」提供的倍率 | $\times2.0\to\times2.2$ |
| 27Mult | $1$ | 第 2 与第 7 反物质维度获得基于无限次数的倍率 | $1+\frac{Infinities}{5}$ |
| 45Mult | $1$ | 第 4 与第 5 反物质维度获得基于无限次数的倍率 | $1+\frac{Infinities}{5}$ |
| galaxyBoost | $2$ | 所有星系强度翻倍 | $\times2$ |
| **第 3 列** |  |  |  |
| timeMult2 | $3$ | 反物质维度获得基于当前无限已用时间的倍率 | $\max\left(\left(\frac{Minutes}{4}\right)^{0.25},1\right)$ |
| unspentBonus | $5$ | 基于未花费无限点数为第 1 反物质维度提供倍率 | $1+\left(\frac{IP}{2}\right)^{1.5}$ |

| passiveGen | $10$ | 以比最快无限慢 10 倍的速度被动生成无限点数 | 按等于最快无限时间的间隔生成 $1$ 基础 IP，再除以 $10$ |
| **第 4 列** |  |  |  |

| skipReset2 | $40$ | 每次重置开始时拥有 $2$ 次维度提升，自动解锁第 6 反物质维度 |  |
| skipReset3 | $80$ | 每次重置开始时拥有 $3$ 次维度提升，自动解锁第 7 反物质维度 |  |
| skipResetGalaxy | $300$ | 每次重置开始时拥有 $4$ 次维度提升，自动解锁第 8 反物质维度，并拥有一个反物质星系 |  |
