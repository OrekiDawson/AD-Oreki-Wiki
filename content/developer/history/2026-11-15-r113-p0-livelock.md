> 本页是历史归档，记录当时的根因定位与验证范围，**不代表当前状态**。现行机制解释见 [Kotlin 混合运行时 ABI](/developer/architecture/kotlin-runtime)。

## 事件与时间

2026-11-15，AGP 完整游戏候选出现「能构建、能启动，但游戏 tick 不推进、不写存档」的问题。R113-01 用 AVD 线程栈与对照构建定位根因，修复合并为 PR #88。

## 当时结论

- **全量 enjarify 会 livelock**：`AntimatterGameThread` 的 Runnable 卡在 `SpeedrunMilestone$complete$1.invokeSuspend → Player.l0/k0 → … → vf2.d`（utm≈127 秒），tick 不再推进，30 秒周期存档与 HOME 保存都不触发；smali 稳定版同线程为 `Waiting/park`。
- **全量 dex2jar 会 VerifyError**：dex2jar 把 DEX 的 `new-instance 子类 + invoke-direct 父类构造器` 改写成 `new 父类`，ART 直接拒绝（实测 `kn6.z`、`k51.e`）。
- **正确形态是 J8 混合**：官方基础用 enjarify，指定协程调度热路径类改用 dex2jar（默认 `ox0,gk0,dc2,tf2,vf2,t01`）；补丁类检测改为 enjarify 对 enjarify 比较；最终 jar = 官方基础 + 仅补丁类覆盖；新增 `hierarchy` 与 `dash_rename` fail-closed 守卫。

当时验证（同一 APK `f2f72a61…`、jar `dec24f57…`、15,344 类）：

| 项 | 当时结果 |
| --- | --- |
| 新档自动存档首写 | PASS，40.2 秒 |
| HOME 保存 / force-stop 保留 / 重启读取 | PASS |
| 合法晚期存档（realities=12、Lai'tela、11 glyph）读写 | PASS |
| 挑战自动化 5 分钟 | PASS（功能性，0 FATAL / 0 ABI 崩溃 / 0 ANR） |
| AGP↔Smali 晚期存档互读 | NOT RUN |
| 新档 ≤180 分钟真实通关 | NOT RUN（当时长跑进行中） |

## 后续变化与是否仍然有效

- **仍然有效**：J8 混合转换形态仍是构建路径的一部分；A 批 ABI 与 hierarchy/dash 守卫继续生效。
- **当时「功能闭环 PASS」不等于通关**：随后的 180 分钟长跑为 FAIL（见 [2026-11-15 · R113-01 新档 180 分钟长跑 FAIL](/developer/history/2026-11-15-r113-180min-fail)）。
- 跨构建晚期存档互读至今仍未完成（见 [存档兼容与自动保存](/player/gameplay/saves)）。
