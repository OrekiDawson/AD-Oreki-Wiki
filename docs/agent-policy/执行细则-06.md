# 公开门面与首页执行细则

> 现行详细规则，按根 AGENTS.md 的触发范围读取。跨仓重复约束以 Workspace 为权威，不重复加载；根入口的新规则优先。保留原条款及章节，链接按新位置调整。

## 公开门面与首页

README.md 与 content/index.md 面向普通读者，是项目的公开门面，不得写入 Agent 调度、内部审计、Kody 配额、CI 门禁、HTTPS 管理、PR 流水或重构台账等操作信息。仓库维护细节应放在维护文档，文章质量规则应放在知识库规则；公开首页也必须遵守同一原则。README 至少保留站点入口、玩家/开发者导航、贡献方式、来源与版权许可。每次修改门面后，应检查构建产物与线上首页，确认读者看到的是清晰的双专区入口。
