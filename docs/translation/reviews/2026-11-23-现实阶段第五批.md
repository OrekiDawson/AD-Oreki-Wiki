## 来源读取与边界

2026-11-23 执行本批审校时，wiki.gg 的旧修订 API 再次返回 HTTP 403，无法把四个目标 `oldid` 重新下载为新的字节级回执。本次没有把历史成功调用、归档快照或源码匹配说成目标修订的实时 HTTP 200。

本批使用的材料如下：

- **现有全量译文与固定元数据**：四篇页面均已有与 manifest 一致的完整正文、`original_revid`、最后编辑者与抓取时间。逐段核对以这些正文为单位，不把章节存在当作审校完成。
- **本机 wiki.gg 正文快照**：`Reality` 与 `Black Hole` 使用项目在 2026-11-10 从 wiki.gg API 保存的正文快照。`Reality` 快照 SHA-256 为 `fcbc9f6f3f2d3fedb0aac08396388ed88d13014252e432c07613bb6d41b46b20`；`Black Hole` 快照 SHA-256 为 `318cddbff916a14eee43dc02ae1b43ef6f43d636e2efc107aadc265a98d2ed11`。这两个文件未保存抓取时的 `revid`，因此只作为目标元数据之外的正文辅助。
- **Internet Archive 固定快照**：[Reality Upgrades（2026-09-26，修订 3124）](https://web.archive.org/web/20260926223835id_/https://antimatterdimensions.wiki.gg/wiki/Reality_Upgrades)与 [Black Hole（修订 3126）](https://web.archive.org/web/20261003125710id_/https://antimatterdimensions.wiki.gg/wiki/Black_Hole)用于核对旧正文结构和表格。它们早于 manifest 中的目标修订，只作辅助证据。
- **Fandom 镜像**：[Alchemy](https://antimatter-dimensions.fandom.com/api.php?action=parse&page=Alchemy&prop=wikitext&format=json&formatversion=2) 于本次实际读取成功，用于补足 wiki.gg 正文快照中未完整显示的炼金说明；它是镜像正文，不冒充 wiki.gg 的 `oldid=3388`。
- **官方源码**：固定到 [IvarK/AntimatterDimensionsSourceCode@`5409e32`](https://github.com/IvarK/AntimatterDimensionsSourceCode/tree/5409e320cecef96a917cca1dfb68f1f183e499ca)，逐项核对入口条件、公式、成本阶段、重置调用和黑洞状态机。

因此，本批能证明的是“完整正文与固定元数据已逐段语义审校，并以源码交叉检查关键规则”；不能声称完成了 2026-11-23 的 wiki.gg 目标 `oldid` 字节级 API 比对，也不能声称启动了游戏逐项实测。
