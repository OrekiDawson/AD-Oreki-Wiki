## 来源读取与边界

2026-11-23 执行本批时，wiki.gg 的 `action=parse&oldid=...&prop=wikitext` 仍被 Cloudflare 以 HTTP 403 阻断。按页面名查询当前 `revid` 可以访问，但那返回的是更新后的当前修订，不能冒充四个清单目标修订的实时回执。

本批采用以下证据层级：

- **目标元数据和现有全量正文**：四篇页面已有 manifest 固定 `revid`、编辑时间、编辑者与完整中文正文，逐段检查以现有正文为对象。
- **Fandom 镜像固定修订**：[Perks（oldid `8158`）](https://antimatter-dimensions.fandom.com/api.php?action=parse&oldid=8158&prop=wikitext&format=json&formatversion=2) 与 [Imaginary Upgrades（oldid `8109`）](https://antimatter-dimensions.fandom.com/api.php?action=parse&oldid=8109&prop=wikitext&format=json&formatversion=2) 于本次实际读取成功。它们只作语义补足，不冒充 wiki.gg 的目标修订。
- **本机与归档快照**：`Time Dilation` 使用本机 2026-11-10 保存的 wiki.gg 正文快照；Internet Archive 的 [Perks](https://web.archive.org/web/20260820124712id_/https://antimatterdimensions.wiki.gg/wiki/Perks) 与 [Dilation](https://web.archive.org/web/20261003125710id_/https://antimatterdimensions.wiki.gg/wiki/Dilation) 固定快照用于结构和公式辅助核对。快照时间早于部分目标修订，不能替代目标 `oldid`。
- **官方源码**：固定到 [IvarK/AntimatterDimensionsSourceCode@`5409e32`](https://github.com/IvarK/AntimatterDimensionsSourceCode/tree/5409e320cecef96a917cca1dfb68f1f183e499ca)，按具体文件核对复兴图、虚幻机器、充能倍率与膨胀公式。

因此本批结论是“完整正文已逐段语义审校，并与源码交叉核实”；不是目标 `oldid` 的字节级比对，也不是游戏逐项实测。
