## 来源读取与降级边界

2026-11-23 直接通过命令行与只读代理请求 wiki.gg 的 MediaWiki API 和页面时，均被 Cloudflare 安全页以 HTTP 403 阻断，无法把最新目标修订正文标为“已直接读取”。

本批没有用模型记忆代替来源，而是同时使用以下可复核材料：

- Internet Archive 的 wiki.gg 固定页面归档：Infinity Upgrades `oldid=3114`、Antimatter Galaxies `oldid=3112`、Dimensional Sacrifice `oldid=3111`。
- 本机 Android 验收目录在 2026-11-14 从 wiki.gg API 保存的 `wiki.gg__Tickspeed.txt`；其正文与清单 `oldid=3334` 的 2026-10-18 修订对应，SHA-256 为 `e8544c21fa141a18eeea9894d938802e6c01ffd014249342d64d6af3a15b98a6`。
- 原版 Web 源码中的 `src/core/tickspeed.js`、`src/core/sacrifice.js`、`src/core/galaxy.js`、`src/core/infinity-upgrades.js` 和对应配置表，用于核对公式、边界、前置条件与术语。
- Fandom 的旧 MediaWiki API 作为辅助文本对照，仅用于发现漏段，不作为 wiki.gg 最新修订编号的证明。

因此，本批是**固定英文修订与官方源码交叉审校**，不是最新目标修订的逐字节比对；`VERIFIED AGAINST GAME` 仍未完成，因为没有启动游戏进行逐项界面与运行复核。

## 结论与边界

四篇正文已完成逐段语义审校，状态由 `STRUCTURE CHECKED` 提升为 `REVIEWED`。本批实际修复：

1. 反物质星系页错误的时间研究编号。
2. `resetBoost` 对维度提升与反物质星系的不同数值说明。
3. 维度献祭脚注、公式含义和挑战差异。
4. 计数频率的术语、重复来源行与无限后价格说明。
5. 原版译文首页的媒体署名主语。

`VERIFIED AGAINST GAME` 保持未完成：本批只核对了官方源码和固定英文资料，没有启动游戏逐项验证按钮、界面文字和运行数值。当前目标修订无法由 wiki.gg 直连读取这一点也不应被隐藏；后续网络恢复后可再对 `3348/3397/3335/3334` 做一次逐字节来源复核。
