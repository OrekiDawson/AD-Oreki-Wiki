## 来源读取与边界

- **目标修订与历史正文**：`Eternity` 使用 Internet Archive 的 [2026-10-03 固定快照](https://web.archive.org/web/20261003125710/https://antimatterdimensions.wiki.gg/wiki/Eternity)，快照中的 `wgRevisionId=3118`，与清单一致。`Eternity Challenges` 使用本机 2026-11-10 从 wiki.gg API 保存的正文快照，SHA-256 为 `8e25f96f7128946b747e5cbfa4d0d4ca42e8cf99f7c71a25a19ddd32e3a2d6a7`；文件导出于目标修订最后编辑日之后。
- **较旧固定快照**：[Time Dimensions（2026-08-20，修订 2545）](https://web.archive.org/web/20260820124705/https://antimatterdimensions.wiki.gg/wiki/Time_Dimensions)用于核对章节、表格和公式结构；[Eternity Challenges（2026-08-20，修订 2426）](https://web.archive.org/web/20260820124728/https://antimatterdimensions.wiki.gg/wiki/Eternity_Challenges)用于核对挑战说明。
