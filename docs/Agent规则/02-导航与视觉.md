# Wiki 导航与视觉细则

本文件是根 AGENTS.md §3 的强制细则，适用于 Quartz 配置、导航模型、共享组件、公开素材、页面兼容和浏览器验收。

## 1. 信息架构与公开边界

### 1.1 正式条目的发现
- 玩家、开发者双专区具有真实正文、独立分类导航和清晰首页入口。正式条目从分类或自动生成的全部条目索引可达，覆盖率目标 100%；搜索、反向链接或已知 URL 不能替代导航。
- 全部条目由实际正式内容树生成或校验，不维护易漂移的手工副本。禁止无合理依据的孤立页、重复入口、失效导航链接、空虚拟分类和旧兼容入口暴露；不按文件修改时间向读者推荐文章。
- 导航名称以读者理解为准，短标题、语义排序、合理分类和较浅层级优先。原版译文可按实际游戏主题组织，正式标题使用原版命名空间。
- 合并、拆分、迁移、新增与归档同步维护分类、全部条目、站内链接、站点地图和必要旧 URL 兼容。

### 1.2 Explorer 交互
- 使用 ordered-explorer。正式分类默认完整展开；没有真实下级正式页面的索引目录直接渲染普通链接，不显示箭头、空子菜单或虚假分组，不为保留按钮建立占位页。
- 桌面分类标题进入分类索引，可用独立折叠按钮，保存读者展开状态；SPA 切页仅自动展开当前路径祖先，不强制重置其他分类。当前条目自动高亮与定位。
- 移动端只控制整个导航面板的开启/关闭，分类不逐个折叠；抽屉即时响应、独立滚动、正文不随抽屉发生横移。不能通过隐藏正式条目解决导航冗长。
- CI 检查导航模型、内容覆盖、重复与失效链接、草稿/归档泄露、初始展开及构建后 DOM；移动和桌面真实浏览器分别验收。

### 1.3 归档、旧 URL 与索引
- 内部历史任务、失败报告、交接、旧构建与审查证据迁出 Quartz content/，保留 Git 历史及内部资料，不能以 CSS 或仅设置 unlisted 代替排除。
- 仍需保留的历史参考旧文章以 archive: true 及必要 replaced_by 作为统一依据；排除公开 HTML（必要兼容入口除外）、导航、全部条目、搜索、相关推荐、RSS、站点地图、关系图和反向链接。不得以分散路径黑名单、时间或 CSS 代替统一依据。
- 旧入口只用于兼容路由或重定向，不能作为正式文章、导航或检索结果。保护已经发布的有效旧 URL 与原始历史证据；必要时将有价值知识核实去重后纳入现行正文。
- 关闭 Quartz Graph 的全局、局部、交互入口及相应公开组件配置，不用 CSS 掩盖。保留目录、有效相关推荐、回链与搜索所需数据。
- 未审核 AI 草稿绝不进入公开产物。AI Summary 仅为有来源、适用版本、经审核且默认折叠的开发者附属材料，不代替技术正文或进入主要学习导航。

## 2. 视觉、排版与共享组件

### 2.1 设计标准
- 继续使用 Quartz、Markdown 和 GitHub Pages，不为模仿百科视觉迁移框架。参考 MediaWiki 式紧凑阅读体验，统一页眉、站名、搜索、侧栏、目录、正文宽度、标题层级、引用、分类及手机布局。
- 默认以深色模式为设计基准，浅色完整适配，保留主动主题切换与偏好。共享组件采用语义颜色变量，正文与关键控件满足 WCAG AA 对比度要求；图表避免突兀白底、低对比度文字及装饰性阴影、渐变。
- 保留 Quartz SPA 快速客户端导航，取消进度条、切页动画、View Transition 和人为延迟；验证点击、前进后退、锚点及搜索不受损。
- 全站使用系统无衬线及系统等宽字体，禁用普通第三方网页字体、Google Fonts 及相关预连接。KaTeX 等实际功能字体例外。CI 检查配置、构建产物及数值语义；Playwright 核对实际计算样式。
- 集中维护 Infobox、Wikitable、Navbox、消歧义及主条目提示、Gallery、术语提示、参考资料、机制图、数学曲线和有必要的交互组件。正文提供语义数据，不逐篇复制样式；不伪造编辑、讨论或历史入口。
- README、首页、双专区入口是公开门面；保留站点入口、贡献、许可及来源，不展示内部调度、审核状态、机器属性或重构流水。

### 2.2 实际视觉验收
- 先深色移动端（约 360–430 CSS px），再深色桌面，后浅色移动及桌面、主题切换。检查实际布局、链接、导航高亮、独立滚动、搜索、表格、图解、信息框、公式、代码及横向溢出，适用时检查字号和计算样式。
- 按风险保留必要截图、候选 HEAD、测试环境、真实错误及结论；不以静态构建、脚本语法或报告代替读者界面的真实可用性。
- 导航交付还应核实正式条目总数、覆盖数量、孤立页、归档排除、旧 URL、CI 和部署版本；更新与验收范围应匹配实际改动，避免无意义重复全站审计。

## 3. 素材版权与图文

- 第三方文字、截图、图标、Logo、字体、样式和程序组件分别记录来源、权利人、许可证、使用范围、修改说明和必要署名。不得把第三方资源一律视为本站 CC BY-SA 4.0。
- 维护版权页及现有 docs/translation/original-image-manifest.json；新增、替换、删除素材同步清单。保留合法原版图文的知识关系；不将原版图片全面恢复、外部 Wikipedia 维护或额外图片引用数量设为任务 KPI。
- 来源、许可无法确认的素材不下载发布、不热链、不移除水印/版权标识、不用 AI 虚构截图冒充真实游戏。合法图解提供准确中文替代文本与必要图注，检查本地路径、构建产物及深浅色阅读。
- 人工维护的原创资源优先简体中文名称；技术关键路径例外。旧文件改名须同步全部引用，不制造 404。
