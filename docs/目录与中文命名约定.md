# Wiki 仓库目录与中文命名约定

Wiki 面向中文玩家与开发者。**正文、导航、文章标题与维护说明以简体中文为准**，但 Quartz、Node、TypeScript、GitHub Pages 所依赖的固定文件名和现有页面 URL 不强制汉化。

## 根目录说明

| 位置 | 职责 |
| --- | --- |
| `README.md` | 唯一根目录项目入口，面向读者与贡献者 |
| `AGENTS.md`、`CLAUDE.md` | Agent 编辑与交付规则 |
| `LICENSE.txt`、`LICENSE-CONTENT.md` | 软件、原创中文内容许可与版权范围，保持约定入口 |
| `content/` | 正式公开百科条目与页面；遵循玩家/开发者分区及现有 URL 兼容规则 |
| `docs/` | 编辑手册、翻译规则、条目模板和构建维护说明 |
| `evidence/`、`reports/` | 经脱敏的测试与事实证据；不直接当作百科正文发布 |
| `scripts/` | 内容检查、构建与验证脚本 |
| `.github/`、`.ai/` | 工作流与工具配置，非普通玩家内容 |
| `quartz.*`、`package*.json`、`tsconfig.json`、`Dockerfile`、`*.d.ts` | Quartz/Node/TypeScript 工程入口，文件名由工具链约束 |

## 统一规则

1. 新文章的**展示标题、摘要、正文、导航和主要维护文档用自然简体中文**，避免直接把英文机器结构或 PR 日志复制成百科条目。
2. 文件名可按实际内容使用中文，但若改名会改变站点路由，必须验证旧 URL 仍可访问或有有效重定向；不能仅为“汉化”破坏外部链接、搜索或 Pages 构建。
3. **下一次 Wiki 正式交付的强制门禁**：`/player/` 玩家专区与 `/developer/` 开发者专区必须真实可访问，具有实际内容和导航，旧 URL 兼容，完成移动端、搜索、Quartz、CI 与 HTTPS 线上验证；任一关键项未满足记为 `BLOCKED`。未迁移或仅占位不得宣称已上线。AI Summary 只适用于经审核的开发者内容。
4. 技术组件、Quartz 配置、模块导入、Node/NPM 命令、GitHub workflow 名和许可证文本不强制翻译或重命名。
5. 历史证据归入 `evidence/` 或 `reports/`；对外说明归 `docs/`；不要在根目录追加临时进度、生成草稿或未审网页。
6. 所有路径调整按最小必要校验执行 `node scripts/check-content.mjs`、`npx quartz build` 等适用检查；未经实际运行不能记录 PASS。
