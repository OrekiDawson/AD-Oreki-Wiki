## 读者首选路径

### 第一次来玩

1. 首页选择玩家专区。
2. 从“开始游玩 Oreki Edition”完成第一次大坍缩，并确认 Android/Web 的下载与存档边界。
3. 按“无限与永恒 → 现实与时间研究 → 天神/终局”继续阅读。
4. 遇到自动化、按钮或存档问题，进入 FAQ 与存档安全页；不要把开发状态页当作玩家操作指南。

### 第一次参与开发

1. 首页选择开发者专区。
2. 从“第一次参与开发”完成 Web 最小上手闭环。
3. 分别阅读 Android 与 Web 架构，找到真实启动入口、模块职责和数据路径。
4. 按任务进入 AGP/R8、CI、签名、存档兼容或故障排查。
5. 当前状态、发布状态、历史归档和 AI Summary 只作为辅助入口。

### 查阅原版资料

1. 从玩家专区进入原版 Wiki 中文翻译。
2. 按原版页面修订与来源查看译文，不把 MOD 缩放、调度器或发布边界混入原版机制。
3. `TRANSLATED`、`STRUCTURE CHECKED`、`REVIEWED`、`VERIFIED AGAINST GAME` 分别统计，不互相替代。
