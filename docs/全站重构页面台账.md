## R130 最终收口范围

本轮只处理现有公开页面的质量整改、审查、合并、部署与线上验收：原创页按最新公开方针完成作者化表达，原版译文保持忠实，公开页面清除 GitHub 具体文件外链，并完成必要的导航、标题、字体、链接和桌面/移动阅读检查。公共 Wikipedia 维护与跨语言调查、图片引用/补全/原版图片恢复专项，以及与现有页面质量无直接关系的扩展任务均已取消；已取得且许可明确的素材保留，图片缺失不作为本轮完成阻断。达到逐页验收条件后立即更新本台账、保存证据并结束 R130，不以新增页面或无限润色延长任务。

“作者化表达”是独立验收列，不与正文修改、Lead 复审或上线状态合并。原创页面按“待评估 / 不合格 / 整改中 / 待复审 / 合格”记录；原版忠实译文等页面记录“不适用”。CI、Kody、合并或上线通过均不能自动推导为作者化表达合格。MediaWiki 式导航、目录、标题层级、正文宽度、表格、引用、内链、系统字体、深浅色模式、移动端适配及取消切页动画仍属于本轮最终 UI 验收；取消的是公共 Wikipedia 维护任务，不是界面标准，也不要求迁移 Quartz。

## 读者首选路径

### 第一次来玩

1. 首页选择玩家专区。
2. 从“开始游玩 Oreki Edition”完成第一次大坍缩，并确认 Android/Web 的下载与存档边界。
3. 按“无限与永恒 → 现实与时间研究 → 天神/终局”继续阅读。
4. 遇到自动化、按钮或存档问题，进入 FAQ 与存档安全页；不要把开发状态页当作玩家操作指南。

### 第一次参与开发

1. 首页选择开发者专区。
2. 从“第一次参与开发”完成 Web 最小上手闭环。
3. 分别阅读 Android 与 Web 架构，找到真实启动入口、模块职责和数据路径。
4. 按任务进入 AGP/R8、CI、签名、存档兼容或故障排查。
5. 当前状态、发布状态、历史归档和 AI Summary 只作为辅助入口。

### 查阅原版资料

1. 从玩家专区进入原版 Wiki 中文翻译。
2. 按原版页面修订与来源查看译文，不把 MOD 缩放、调度器或发布边界混入原版机制。
3. `TRANSLATED`、`STRUCTURE CHECKED`、`REVIEWED`、`VERIFIED AGAINST GAME` 分别统计，不互相替代。
